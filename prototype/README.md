# Prototype

The 18 screens of CriticalEye, with fictional patients. Open [`index.html`](index.html) in Chrome, Edge or Firefox; it works straight from the file system. The screens are in Portuguese.

| Folder | What it is |
| --- | --- |
| `source/` | The screens as exported from the design canvas: `*.dc.html`, `canvas.json` (board titles and layout) and `assets/` (icon and logo). Change these. |
| `screens/` | One runnable page per screen, generated by `viewer/build.mjs`. Do not edit by hand. |
| `screenshots/` | Full-page PNG of each screen in its starting state, 1366 px wide. |
| `viewer/` | `dc-lite.js` (the small runtime the pages load), `build.mjs` and `screenshots.cjs`. |

## Clickable screens

Entry, bed full view, bed summary view, blank bed CTI 1, blank bed CTI 2, copy progress note, shift handoff and brain-death protocol run their own logic. The other screens are drawings of one state.

Things to try in the blank bed screens (`Branco`, `Cti2`):

- Type a date of birth and a weight: age, infusion dose and urine output in ml/kg/h appear.
- In Dispositivos, add a drain (Hemovac, chest drain, DVE): it gets its own loss line in the fluid balance.
- Change the drug in Hemodinâmica: the unit's standard concentration fills in, and you can still edit it.
- In Infecção, choose Linezolida: the restricted-antibiotic warning appears.
- In Respiratório, choose CN: only the O₂ flow field remains.

## How the source format works

- `<x-dc>` wraps the screen; `<helmet>` holds the fonts and styles that go in the page head.
- `{{name}}` is filled from `renderVals()`. `<sc-if value="{{name}}">` keeps its content only when that value is truthy.
- `onClick`, `onChange` and `onBlur` take handlers returned by `renderVals()`. `this.setState()` triggers a new render.
- `data-props` on the component script sets defaults such as the hospital and ICU names.

`viewer/dc-lite.js` implements just this and rebuilds the screen's HTML on every state change, keeping focus and typed text. It is prototype tooling only.

## Rebuilding

```sh
node prototype/viewer/build.mjs        # after changing anything in source/
npm i -D playwright && npx playwright install chromium
node prototype/viewer/screenshots.cjs  # optional: refresh the PNGs
```

The pages load IBM Plex Sans from Google Fonts. Offline, they fall back to a system font.
